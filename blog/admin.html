수정 방법

아래 글의 ‘편집’ 버튼을 누르면 GitHub 공식 편집기가 열려요. 맨 위의 title, subtitle, image 같은 항목은 글 정보이고, --- 아래가 실제 본문이에요. 수정 후 Commit changes를 누르면 블로그에 반영됩니다.

이 페이지에는 비밀번호나 GitHub 토큰을 저장하지 않아요. 실제 저장 권한은 GitHub 로그인 계정으로 확인합니다.
